NovaRegistry

interface NovaRegistry<out T : NovaRegistryElement<T>>

A thread-safe storage for values identified by keys.

During initialization (bootstrap), elements of registries cannot be accessed. Instead, use registry entries and entry sets, which will be bound to the corresponding values upon registry freeze.

Elements of registries can be grouped together using tags, which are also identifiable by a Key.
