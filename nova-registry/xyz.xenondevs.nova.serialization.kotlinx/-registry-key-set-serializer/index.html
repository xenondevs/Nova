RegistryKeySetSerializer

open class RegistryKeySetSerializer<T : Keyed>(val registryKey: RegistryKey<T>, val registryAccess: RegistryAccess = RegistryAccess.registryAccess()) : JsonTransformingSerializer<RegistryKeySet<T>>

Open base class for specialized RegistryKeySet serializers. Serializes a tag to #namespace:value and a direct key set to ["namespace:value1", "namespace:value2"] (or just "namespace:value" if there's only one entry).

This is a JsonTransformingSerializer as it needs to support both arrays and primitive values, so it can only be used for JSON.
