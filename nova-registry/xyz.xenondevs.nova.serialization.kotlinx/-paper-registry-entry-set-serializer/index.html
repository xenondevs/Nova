PaperRegistryEntrySetSerializer

open class PaperRegistryEntrySetSerializer<T : Keyed>(val registryKey: RegistryKey<T>, val registryAccess: RegistryAccess = RegistryAccess.registryAccess()) : JsonTransformingSerializer<RegistryEntrySet.Paper<T>>

Abstract base class for specialized RegistryEntrySet.Paper serializers. Serializes RegistryEntrySet.Paper.Tag to #namespace:value and RegistryEntrySet.Paper.Direct to ["namespace:value1", "namespace:value2"] (or just "namespace:value" if there's only one entry).

This is a JsonTransformingSerializer as it needs to support both arrays and primitive values, so it can only be used for JSON.
