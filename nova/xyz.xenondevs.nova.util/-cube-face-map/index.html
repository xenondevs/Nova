CubeFaceMap

data class CubeFaceMap<out V>(val north: V, val east: V, val south: V, val west: V, val up: V, val down: V)

An immutable map from each BlockFace (of the cube faces BlockFace.NORTH, BlockFace.EAST, BlockFace.SOUTH, BlockFace.WEST, BlockFace.UP, BlockFace.DOWN) to a value of type V. Keys cannot be absent, use null to model absence instead.
