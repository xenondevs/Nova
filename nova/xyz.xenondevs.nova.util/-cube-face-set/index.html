CubeFaceSet

@JvmInline
value class CubeFaceSet

An immutable set of BlockFace values (of the cube faces BlockFace.NORTH, BlockFace.EAST, BlockFace.SOUTH, BlockFace.WEST, BlockFace.UP, BlockFace.DOWN) stored as a bitmask in a single Byte.

Bit layout (MSB to LSB): 0 | 0 | DOWN | UP | WEST | SOUTH | EAST | NORTH
